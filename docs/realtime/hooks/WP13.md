## Routen / Dateijob

In sirens/realtime/routes.py bei den Offline-Jobs nach ADR 0006 einen POST-Start für SAM (Vorschlag:
`/api/rt/v1/semantic/jobs`) ergänzen. Bestehende GET jobs/{id}, POST jobs/{id}/cancel und GET assets/{id}
wiederverwenden. Payload nur asset_id bzw. relativer Songpfad und prompt; Host/Origin/JSON prüfen,
SIRENS_RT_ENABLED und Capability/GPU-Lease erzwingen, safe_audio_path bzw. serverseitige Assetauflösung.
Keine Pfade, Modellrevisionen, Worker-Befehle oder Ausgabedateinamen aus HTTP übernehmen.
Bei Nichtfreigabe unavailable, bei ungültigem Prompt invalid. Eingabe zunächst PCM16-Stereo 44,1/48 kHz;
andere Formate serverseitig in privaten Cache normalisieren, niemals Original überschreiben.

**Anpassungsbedarf ADR 0006:** eingefrorenes Capability-Schema unterstützt nur numerische Controls.
Textprompt ist deshalb noch nicht als Control darstellbar. WP25/Koordinator muss den einzigen
SAM-Dateijob-Parameter `prompt` explizit als Text (max. 512 Zeichen, keine Steuerzeichen) zulassen,
nicht die allgemeine Payload-Validierung aufweichen. Kein Schemawechsel durch WP13.
IPC-Annahme: file_job payload {job_id, source, out_dir, params}, result {files: ["target.wav", "residual.wav"]}.
Vor Verdrahtung gegen tatsächliche WP25-Schnittstelle abgleichen.

Integration nach Freigabe (im vorhandenen serverseitigen Job-Lock, Supervisor und Jobstatus nutzen):

```python
from workers.sam_audio.adapter import prompt_value
from workers.sam_audio.cache import SemanticCache
params = {"prompt": prompt_value({"prompt": request_prompt})}
cache = SemanticCache(cfg.realtime_dir / "semantic-cache", music_root)
digest, key, hit = cache.lookup(source, approved_revision, params)
# Hit: nur bei aktiver Capability, als Assets des aktuellen Jobs registrieren.
# Miss: Supervisor mit GPU-Lease und Nutzeraktion starten, dann:
supervisor.request("load", timeout=120)
result = supervisor.request_file_job(job_id, source, out_dir, params, timeout=600)
# Supervisor prüft relative Dateiliste, benennt den privaten Ordner atomar um.
# staging = dessen veröffentlichter Ordner; bei Erfolg unter Job-Lock:
directory = cache.publish(source, staging, digest, approved_revision, params, cancelled)
# Nur target.wav / residual.wav als Asset-IDs veröffentlichen; nie absolute Pfade.
```

Hit/Miss, Cancel und Publish serialisieren; bei Abbruch Supervisor.cancel() / Prozessbaum beenden,
privaten Ordner löschen, keine Assets registrieren. Cache-Publish konsumiert staging per Rename,
bei bereits vorhandenem gültigen Cache staging durch Job-Controller aufräumen. Timeout und Lease
im finally behandeln. Heartbeat-Fortschritt aus payload.progress (0..1).
Cache und Audio nur lokal außerhalb Musikordner; bei Änderungen der Normalisierung/Revision Cache-Key ändern.

## Oberfläche

In RTX Neural Lab (shell.js bzw. berechtigter KETTE-43-Integration) neben Stem Studio Textfeld,
Start, Fortschritt, Cancel, Vorhören Ziel/Rest und Dry (Original), keine Streaming-Anzeige.
Vorhören nur nach validiertem Jobresultat über Asset-IDs im bestehenden Player, kein zusätzlicher
AudioContext; synchroner Start und gleiche Länge/Rate. Keine automatische Lautheitsnormalisierung
beider Stems. Hinweis: „Trennung kann Artefakte enthalten; keine perfekte Isolation garantiert.“
Bis Gate/Installation/Jobverdrahtung und Hörprüfung deaktiviert lassen.

Registry- und HTTP-Bestandstests erwarten ohne installierte Modelle eine leere Capability-Liste.
Deshalb keine automatisch registrierte Manifestdatei im Repo bis zur Freigabe. Die Oberfläche zeigt
stattdessen den gesperrten Platzhalter. Lokale Aktivierungsdatei nicht committen ohne abgestimmte Tests.
