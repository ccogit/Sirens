# WP09 – DSP Rack (CPU, noch nicht freigegeben)

Der Audio-Kern bleibt Eigentum von WP04. Kein zweiter AudioContext, kein zusätzlicher Ausgabepfad. Die folgenden Schritte sind ein Hook für WP31; nicht in WP09 an gemeinsamen Dateien ausführen.

## AudioWorklet

In `web/js/realtime/worklet_processor.js` importieren:

```js
import {RackPath} from "./effects/rack.js";
```

Im Konstruktor von SirensProcessor optional (nur bei expliziter DSP-Aktivierung und bestandenem Gate) je RenderPath einen RackPath mit demselben Profil erzeugen, außerhalb von process:

```js
this.racks = cfg.dspEnabled === true
    ? this.paths.map(() => new RackPath("fast")) : null;
this.dspOut = new Float32Array(2);
```

In der bestehenden inneren Spur-Schleife unmittelbar nach `p.sample(...)` statt der bisherigen Summierung:

```js
if (this.racks) {
    this.racks[j].sample(p.out[0], p.out[1], this.dspOut);
    l += this.dspOut[0]; r += this.dspOut[1];
} else {
    l += p.out[0]; r += p.out[1];
}
```

Bei allen Epoch-Resets (reset-Nachricht, Loop und verspäteter Reset) jeweils auch den betroffenen RackPath.reset() aufrufen. Der vorhandene Core-Limiter bleibt letzte Stufe. Alle Spuren bekommen dieselbe zusätzliche feste Latenz (fast: 896 Frames); bei gemischten Profilen RackPath(profile, maxLatency) verwenden. Die bestehenden Core-Latenzen nicht um die Rack-Latenz erhöhen, sonst wird Dry doppelt verzögert. Die zusätzliche Latenz getrennt bei Zeitbasis/Recorder angeben.

## Steuerung

In AudioCore.open/constructor optional dspEnabled in processorOptions durchreichen, standardmäßig false. Im Port-Handler neuen Nachrichtentyp dspParam nur für vorhandene Racks akzeptieren (stream 1-basiert, family 0/1/2, key und value). Aufruf `this.racks[m.stream-1].rack.setParameter(m.family,m.key,m.value)` in try/catch, Fehler als Ablehnung zurückmelden; Presets entsprechend applyPreset. Keine beliebigen Eigenschaftsnamen oder dynamischen Imports. UI ausschließlich hinter SIRENS_RT_ENABLED, DSP-Capability vor Gate deaktiviert/„nicht gemessen“. Profilwechsel nur beim gestoppten Neuaufbau; Stretch endlicher Clips vor Übergabe an den Core, nicht im Callback (`stretchStereo`, Eingabe/ Ausgabe interleaved Float32). Kein GPU-Modus.

## Bedienoberfläche

WP31/WP17: pro Effekt Wet, Bypass und Familienparameter als begrenzte Regler (Pitch 0,5–2, Mask 0–1, Freeze boolean, Cloud 0–1, Morph 0–1), Preset-Auswahl neutral/cloud/octave/freeze; Stretch 0,5–2 als Offline-Vorschau. Profil und deklarierte Zusatzlatenz in Frames und ms bei tatsächlicher Context-Rate anzeigen. Kein Label „Echtzeit“ vor Messung. Rückbau: dspEnabled false, keine Racks anlegen.
