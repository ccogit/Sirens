## Vertragshinweise für P01–P07

Assets/Stems optional `plan=...`, `root=...` zur Inhaltsprüfung (SHA-256, WAV-Header, volle Stem-Länge); Ableton optional root. `tests/production/fixtures`: JSON-Vorlagen; `generate(root, plan)` / `write_manifests(root, plan)` erzeugen temporäre WAVs, keine Audiodateien in Git.
