## Lokaler Lauf (Koordinator)

Mit vorhandenen SIRENS_MUSIC_ROOT und SIRENS_DATA_DIR (beide lokal, Datenverzeichnis außerhalb des Checkouts). Ohne AMM-Export werden fehlende AMM-Daten explizit in coverage markiert.

    python -m sirens.production.references inventory
    python -m sirens.production.references inventory --amm-export <lokaler-export.json>
    python -m sirens.production.references references --brief <lokaler-brief.json> --amm-export <lokaler-export.json> --analyse

Ausgabe: aggregierte JSON-Zähler auf stdout und inventory.json bzw. references.json unter DATA_DIR/production/references, Analyse-Cache unter cache/. Keine Dateien ins Repo übernehmen. Ohne --analyse bleiben Audio-Messwerte null. Keine Modellimporte, kein Netzwerk-/GPU-/Live-Zugriff in diesem Modul.

Die Exportprojektion ist ein Adapterformat, kein bereits vorhandenes AMM-API-Format. Aus dem bestehenden lesenden AMM-Referenzlookup pro eindeutigem Artist/Release/Titel/Version die belegten Werte lokal projizieren. Objekt mit schema_version=1 und songs-Liste; je Zeile artist_slug, release_slug, title, version (Integer oder null), style_prompt, negative_tags, lyrics, parameters, axes, song_evaluations (outcome_score, favorite, comment, axes). Fehlende Werte null, fehlende Bewertungen leere Liste. Keine freien SQL-Befehle aus Sirens; kein DB-Schreibzugriff. Automatischer Export benötigt Abstimmung mit AMM-/K00-Owner. Keine privaten Beispielwerte im Git.
