## Lokaler echter Lauf – Windows 11 / Python 3.11

Nur lokaler vertrauenswürdiger Betreiber: SIRENS_DATA_DIR, SIRENS_MUSIC_ROOT, SIRENS_PRODUCTION_CONFIG setzen. Alle Dateien/Pfade/Asset-Rechtebelege außerhalb des Checkouts. .env.example enthält ausschließlich den Konfigurationsnamen.

SIRENS_PRODUCTION_CONFIG ist eine UTF-8-JSON-Datei mit schema_version=1. Schlüssel (lokale Werte, keine Defaults für den konkreten Rechner):

- instrument_python: Pfad zur installierten Instrument-Worker-venv (python.exe); amm_backend: verifizierter WB-Backend-Importroot; instrument_revision: tatsächliche Host-/Plugin-/Preset-Revision; patches: semantisches Patch-Manifest gemäß K03 (alle im Plan vorkommenden Instrument-IDs, inklusive verifizierter Rechte/Presets). Der gemessene DawDreamer-0.9.0-/Surge-XT-1.3.4-Host allein beweist noch nicht, dass WBWorker mit diesen Bindungen funktioniert.
- asset_root: freigegebener lokaler Quellenroot, assets: Objekt pro Asset-ID mit file (relativ zum asset_root), source (backend, revision, license, license_confirmed=true, use; bei Speech exakt text), optional measured (belegter bpm/key). Vorhandene AMM-/SecondRoom-Lieferungen zuerst auswählen; keine Analyse-Referenzen als Samples. asset_python optional für lokale Konvertierung. 
- mix_python: lokaler Mix-Worker-Interpreter; ffmpeg: verifizierter lokaler ffmpeg-Pfad. Optional amm_python und amm_root gemeinsam, analysis_python und analysis_root gemeinsam; amm_checkout für den bestehenden MIDI-Writer; export_root für Archivexport.
- optional amm_export: lokale K01-Projektion; pilot: Objekt brief, plan, preview_brief, preview_plan für die UI; revisions: Objekt exakter Nutzerwunsch -> vom Agenten erstellter neuer Plan.
- Optional nur im Sirens-App-Kontext: confirmed_gap_ids (belegte Kataloglücken), generated_sources (K04-Freigabebelege), gpu_peak_bytes, asset_python, tts_snapshot, stable_python/stable_cache. GPUAdapter.from_app erfordert vorhandene zentrale Admission. **K04s vorhandener Worker erwartet gepinntes Qwen CustomVoice, nicht das am Zielrechner gemessene VoiceDesign-Modell.** Keine falsche Bindung/Umgehung; VoiceDesign-kompatiblen Worker durch P04-Owner abstimmen oder zuvor lokal erzeugte, korrekt lizenzierte und PCM24/48k-konvertierte Speech-WAVs als ausgewählte Assets verwenden. Eigenständige CLI generiert ohne zentrale App-Lease keine GPU-Assets. Keine hart codierten Zielrechnerpfade.

Lokalen Brief (Clear Head, Broken Heart, preview target_seconds 30–60; für K02-Rezept vier explizite kurze freigegebene Textpassagen, einschließlich finalem Refrain) und ggf. agentengeplanten 30–60-s-Plan bereitstellen. Keine echten Lyrics oder Audiodaten committen. PowerShell aus Checkout:

    $env:SIRENS_PRODUCTION_BRIEF = "<lokaler Pfad zu Clear-Head-Preview-brief.json>"

    py -3.11 -m sirens.production inventory
